## 🛠️ الأدوات المُنشأة

### 1️⃣ MCP Server Configuration
**الملف:** `.cursor/mcp_config.json`

```json
{
  "mcpServers": {
    "postgres": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres"],
      "env": {
        "POSTGRES_CONNECTION_STRING": "postgresql://postgres:postgres123@localhost:5432/EventManagementDb"
      }
    }
  }
}
```

**الفوائد:**
- ✅ الاتصال المباشر بقاعدة البيانات من الـ AI
- ✅ تنفيذ استعلامات SQL مباشرة
- ✅ فحص البيانات بدون أدوات خارجية
- ✅ تشخيص المشاكل بشكل أسرع

**الاستخدام:**
- بعد إعادة تشغيل Cursor، سيتمكن الـ AI من الاتصال بقاعدة البيانات مباشرة
- يمكن تنفيذ استعلامات مثل:
  - `SELECT * FROM "Events" LIMIT 5;`
  - `\d "Events"` (لعرض بنية الجدول)
  - فحص الترحيلات المطبقة

### 2️⃣ PowerShell Database Connection Script
**الملف:** `CS-SY-Events/scripts/test-db-connection.ps1`

**الميزات:**
- ✅ اختبار الاتصال بقاعدة البيانات
- ✅ عرض إصدار PostgreSQL
- ✅ عرض قائمة الجداول
- ✅ عرض الترحيلات المطبقة
- ✅ إحصائيات البيانات (عدد السجلات)
- ✅ فحص عمود `Kind` في جدول `Events`
- ✅ دعم معاملات مخصصة

**الاستخدام:**
```powershell
# تشغيل بسيط
cd CS-SY-Events
.\scripts\test-db-connection.ps1

# تشغيل مع معاملات
.\scripts\test-db-connection.ps1 -DbHost localhost -DbPort 5432 -Username postgres
```

**المخرجات:**

### 3️⃣ Common Database Queries
**الملف:** `CS-SY-Events/scripts/common-db-queries.sql`

**المحتوى:** 12 قسم من الاستعلامات الشائعة:

1. **معلومات عامة**
   - إصدار PostgreSQL
   - قائمة الجداول
   - حجم قاعدة البيانات

2. **فحص الترحيلات**
   - جميع الترحيلات المطبقة
   - آخر ترحيل
   - عدد الترحيلات

3. **فحص بنية الجداول**
   - أعمدة جدول معين
   - Foreign Keys
   - Indexes

4. **إحصائيات البيانات**
   - عدد السجلات في كل جدول

5. **فحص البيانات الأساسية**
   - المدن
   - التصنيفات
   - المستخدمين

6. **فحص الفعاليات**
   - جميع الفعاليات
   - حسب النوع (Kind)
   - حسب الحالة (Status)
   - الفعاليات القادمة

7. **فحص الحجوزات**
   - إحصائيات
   - آخر الحجوزات

8. **فحص إعدادات التطبيق**

9. **فحص السلايدر والمربعات المميزة**

10. **استعلامات الصيانة**
    - حذف البيانات (معطلة بالتعليق)
    - إعادة تعيين sequences

11. **استعلامات التشخيص**
    - الاتصالات النشطة
    - حجم الجداول
    - آخر تحديث للإحصائيات

12. **استعلامات مفيدة للتطوير**
    - البحث عن مستخدم
    - البحث عن فعالية
    - صلاحيات المستخدمين

**الاستخدام:**
```bash
# تنفيذ الملف كاملاً
psql -h localhost -U postgres -d EventManagementDb -f scripts/common-db-queries.sql

# تنفيذ استعلام واحد
psql -h localhost -U postgres -d EventManagementDb -c "SELECT * FROM \"Events\" LIMIT 5;"
```
