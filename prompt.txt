صفحات سياسية الخصوصية والأحكام والشروط

توضيحات و زيادات:
1) النطاق واللغة

المنطقة: سوريا فقط.

اللغات: العربية افتراضيًا + الإنجليزية لواجهة النظام (محتوى الفعاليات بالعربية).

i18n: next-intl، مسارات /ar و/en، العربية افتراضي.

2) الحسابات والصلاحيات (RBAC خفيف)

الأدوار: Admin / Organizer / Editor / Support / Viewer.

الزوار يظهر لهم الفعاليات و زر المتابعة يفتح صفحة تسجيل الدخول

المسجلون في الموقع يظهر لهم ايضا توقيمي و عند الضغط على زر متابعة يتم تسجيل متابعته 

كل منظم يستطيع إنشاء/تعديل/حذف فعالياته، والإدارة يمكنها الإخفاء/الحذف/الاعتماد.

اعتماد/رفض الفعاليات: يدوي بواسطة الإدارة.

عرض بيانات المشاركين (حسم التعارض):

Organizer يرى: الاسم، المدينة، المهنة، سبب الاهتمام، وعدّاد المشاركين لفعالياته.

Admin يرى: كل الحقول (بما فيها البريد، الهاتف، الاهتمامات).

التقارير: Admin شامل؛ Organizer لفعالياته فقط.

التنفيذ: Policy Map ثابتة داخل الكود (بدون نظام قواعد ديناميكي).

3) التسجيل والحجز (داخلي)

نوع الحجز: موحّد (لا تذاكر/فئات).

لا سعة قصوى، لا قائمة انتظار.

القبول: تلقائي.

الإلغاء: متاح للمشارك.

الحضور: Check-in يدوي (بدون QR).

التذكير: خيار للمشارك بتوقيت واحد من: 1 / 24 / 72 / 168 ساعة قبل الموعد.

4) البيانات والخصوصية ومكافحة السبام

تسجيل المستخدم: الاسم، البريد (إجباريان)؛ الهاتف، المهنة، المدينة، الاهتمامات، سبب الاهتمام (اختياري).

reCAPTCHA Invisible (v3) قابل للتفعيل/التعطيل من الإعدادات.

لا حذف تلقائي للبيانات؛ الحذف يدوي عند الطلب.

5) النشر على السوشيال (زر “انشر”)

Telegram: إرسال عبر Bot Token + Chat ID.

WhatsApp: مشاركة عبر wa.me link.

Facebook: Share Dialog لمشاركة رابط/نص (بدل Graph API الآن).

قوالب جاهزة (قالبان) بنصوص ديناميكية: {title} {city} {date} {link} وصورة افتراضية.

6) التصنيفات والمحتوى

تصنيفات/قطاعات/مدن: قائمة بسيطة قابلة للإدارة (إضافة/حذف/تعديل).

لا دعم للأحداث المتكررة في هذه المرحلة.

7) التخزين والملفات

تخزين محلي على السيرفر في مسار آمن (مثال: /var/www/data/uploads).

الأنواع: PDF / JPG / PNG / WebP / TXT.

يتم تحويل الصور تلقائيا الى WebP

يمكن اضافة alt للصور

الحد الأقصى: 10MB (متغير بيئي).

الصور: خياران عند الرفع — حفظ الأصل أو توليد Thumbnail واحد WebP بحجم ثابت.

تحسين الموقع للسيو و كافة خيارات السيو الممكنة في لوحة الادارة


8) البحث والتصفية والفرز

تصفية: المدينة / القطاع / التاريخ.

بحث نصي: ILIKE على العنوان/الوصف (مع قابلية ترقية لاحقًا لـ pg_trgm).

الفرز الافتراضي: الأقرب زمنًا ثم الأحدث إنشاءً ثم الأكثر شعبية (الشعبية = عدد الحجوزات آخر 30 يومًا).

9) التقارير والتصدير

المقاييس: إجمالي الحجوزات، نسبة الإلغاء، نسبة الحضور، أكثر المدن/القطاعات نشاطًا، ساعات الذروة، مصادر الزيارات (من Referer/UTM فقط).

التصدير: CSV مع فلاتر (التاريخ/المدينة/الأكثر شهرة/اسم فعالية).

10) تقويم المستخدم

صفحة تقويم شخصية تبين فعاليات المستخدم وحالاتها: محجوز/ألغى/حضر.

لا تكامل خارجي (لا Google Calendar/ICS).

11) غير مشمول الآن

لا مدفوعات إلكترونية.

لا شهادات/QR.

لا CDN.

12) التقنية والتسليم

Auth: بريد/كلمة مرور (قابلة للتوسعة).

رفع ملفات: Route مخصص + فحص نوع/حجم + UUID + منع التنفيذ.

صور: sharp.

AuditLog مختصر (أحداث إدارة أساسية). (لا جدول ReportCache الآن).
