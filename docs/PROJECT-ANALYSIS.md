# 📊 تحليل منصة إدارة الفعاليات في سوريا

**التاريخ**: 14 أكتوبر 2025  
**الإصدار**: 1.0  
**الحالة**: قيد التطوير النشط

## 1️⃣ نظرة عامة على المشروع

### الهدف والرؤية

منصة رقمية موحدة تهدف إلى سد الفجوة بين منظّمي الفعاليات والجمهور المهتم في سوريا، من خلال تقديم نظام مركزي ذكي يسهّل:

- **للمستخدمين**: اكتشاف الفعاليات، التسجيل، التواصل مع المشاركين، ومتابعة الأنشطة
- **للمنظمين**: إدارة الفعاليات، تتبع الحجوزات، والتفاعل مع الجمهور المستهدف
- **للمسؤولين**: مراقبة جودة المحتوى، الموافقة على الفعاليات، وتحليل الأداء

### الجمهور المستهدف

1. **الأفراد**: الباحثون عن فعاليات مهنية، تعليمية، تقنية، ثقافية، واجتماعية
2. **المنظمات**: الجهات التي تنظم المؤتمرات، ورش العمل، الندوات، والأحداث المجتمعية
3. **المؤسسات التعليمية**: الجامعات والمعاهد التي تقيم فعاليات أكاديمية
4. **الشركات التقنية**: المهتمة بالفعاليات التقنية والمهنية

### نطاق المشروع

- **الجغرافي**: سوريا - جميع المحافظات (20 مدينة)
- **اللغات**: العربية (أساسي) + الإنجليزية (واجهة النظام)
- **الفئات**: 22+ فئة (تقنية، تعليم، ثقافة، رياضة، فنون، إلخ)

## 2️⃣ الميزات الرئيسية

### 🎯 الميزات الأساسية (MVP)

#### إدارة الفعاليات
- **إنشاء فعالية**: معالج من 3 خطوات (معلومات أساسية → تواريخ وموقع → مراجعة)
- **تعديل الفعاليات**: للمنظمين والمسؤولين
- **حذف الفعاليات**: مع إمكانية الحذف الناعم (Soft Delete)
- **نظام الموافقة**: موافقة إدارية على الفعاليات الجديدة
  - موافقة فردية
  - موافقة جماعية (Bulk Approve)
  - موافقة تلقائية للمستقبل (قابلة للتفعيل/التعطيل)

#### البحث والتصفية
- **فلاتر متعددة**:
  - المدينة (20 مدينة سورية)
  - الفئة (22+ فئة)
  - التاريخ (من - إلى)
  - المنظم (اسم الجهة المنظمة)
  - الحالة (منقضي / قادم)
  - عدد الحضور (أكبر من X)
- **البحث النصي**: في العنوان والوصف
- **الفرز**: الأقرب زمنياً / الأحدث إنشاءً / الأكثر شعبية

#### نظام الحجز والتسجيل
- **الحجز الداخلي**: بدون دفع إلكتروني
- **التسجيل السريع**: بضغطة زر
- **الإلغاء**: متاح للمشارك
- **التأكيد**: تلقائي بدون موافقة
- **Check-in**: تسجيل الحضور يدوياً

#### التقويم الشخصي
- **عرض شامل**: تقويم كامل مثل Google Calendar
- **الألوان التعبيرية**:
  - 🟢 أخضر: حضرها المستخدم
  - 🔴 أحمر: تابعها وتغيب عنها
  - 🟡 أصفر: انقضت ولم يتابعها
  - 🔵 أزرق: قادمة ولم يتابعها
  - 🟣 بنفسجي: قادمة ويتابعها
- **جدول الألوان**: شرح معنى كل لون
- **التنقل**: بين الشهور والسنوات
- **النقر على الفعالية**: الانتقال لصفحة التفاصيل

#### الصفحة الرئيسية
- **السلايدر القابل للتخصيص**:
  - عدد الشرائح: 2-6 (قابل للتحكم)
  - أنواع العرض: آخر الفعاليات / الأكثر شعبية / مخصص
  - اختيار فعاليات محددة يدوياً
  - إعادة الترتيب (Drag & Drop)
  - تفعيل/تعطيل العناصر
- **المربعات المميزة الثلاثة**:
  - الأحدث (أيقونة ساعة)
  - الأكثر شعبية (أيقونة لهب)
  - مخصصة (أيقونة نجمة)
- **قسم الترحيب**: نبذة عن المنصة

#### رفع الملفات
- **دعم متعدد**: حتى 3 صور + 1 PDF + 1 ملف نصي
- **الأنواع المدعومة**: JPG, PNG, WebP, PDF, TXT
- **الحد الأقصى**: 5MB للصور، 10MB للـ PDF، 2MB للنصوص
- **التخزين**: مجلد `upload/{eventId}/`
- **المعاينة**: عرض الصور قبل الرفع
- **الحذف**: إمكانية حذف الملفات

### 🚀 الميزات المتقدمة

#### ملفات تعريف المشاركين
- **عرض الملف الشخصي**: الاسم، الصورة، المهنة، المدينة، الاهتمامات
- **الفعاليات المشاركة**: قائمة بالفعاليات التي حضرها/سيحضرها
- **التعديل**: الصورة الشخصية، النبذة، الاهتمامات
- **الخصوصية**: إخفاء بعض المعلومات عن العامة

#### منتديات النقاش
- **لكل فعالية**: صفحة نقاش خاصة
- **التعليقات**: إضافة تعليق جديد
- **الردود**: الرد على التعليقات (Nested Comments)
- **التنظيم**: حذف/إخفاء التعليقات غير المناسبة (للمسؤولين)
- **التحديث الفوري**: Real-time (اختياري مع SignalR)

#### جدولة اجتماعات بين الحضور
- **طلب اجتماع**: من مشارك إلى آخر
- **تفاصيل الاجتماع**: التوقيت، المكان، ملاحظات
- **القبول/الرفض**: إدارة الطلبات الواردة
- **الطلبات الصادرة**: متابعة الطلبات المرسلة
- **التقويم المدمج**: عرض الاجتماعات في التقويم

#### التقارير والتحليلات
- **للمنظمين**:
  - إحصائيات الفعالية (عدد التسجيلات، الحضور، الإلغاءات)
  - ديموغرافيا الحضور (المدن، المهن، الاهتمامات)
  - مقاييس التفاعل (مناقشات، اجتماعات)
- **للمسؤولين**:
  - تقارير شاملة لكل الفعاليات
  - أكثر المدن/الفئات نشاطاً
  - ساعات الذروة
  - مصادر الزيارات
- **التصدير**: CSV مع فلاتر

#### المشاركة عبر وسائل التواصل
- **Telegram**: إرسال عبر Bot
- **WhatsApp**: مشاركة رابط مباشر
- **Facebook**: Share Dialog
- **القوالب الجاهزة**: نصوص ديناميكية مع صورة افتراضية

#### الإشعارات والتذكيرات
- **اختيار التوقيت**: 1 / 24 / 72 / 168 ساعة قبل الفعالية
- **البريد الإلكتروني**: إشعارات عبر Email
- **الرسائل النصية**: SMS (قابل للتفعيل)
- **الإشعارات الداخلية**: ضمن المنصة

#### تخصيص ألوان الموقع
- **لوحة الألوان**: اختيار الألوان الرئيسية
- **Theme Customization**: تخصيص مظهر LeptonX
- **الوضع الليلي/النهاري**: Dark/Light Mode
- **الحفظ**: حفظ التفضيلات لكل مستخدم

## 3️⃣ تدفقات المستخدم الرئيسية

### 🌐 الزائر → المتابع

1. **تصفح الفعاليات** كزائر (بدون تسجيل دخول)
2. **الضغط على "متابعة فعالية"**
3. **التوجيه لصفحة التسجيل/تسجيل الدخول**
4. **التسجيل كمتابع فقط** (Viewer Role)
5. **العودة للفعالية** والتسجيل فيها

### 📝 المتابع → المنظم

1. المستخدم المسجل يرى **زر "إضافة فعالية"**
2. **الضغط على الزر** → تظهر رسالة تأكيد
3. **الرسالة**: "سيتم تحويل حسابك من متابع إلى منظم"
4. **الموافقة** → فتح معالج إنشاء الفعالية
5. **تحديث الدور** تلقائياً إلى Organizer

### 🎪 المنظم → إنشاء فعالية

**معالج من 3 خطوات**:

**الخطوة 1: المعلومات الأساسية**
- العنوان (عربي/إنجليزي)
- الفئة
- الوصف (عربي/إنجليزي)

**الخطوة 2: التواريخ والموقع**
- تاريخ البداية
- تاريخ النهاية
- الموقع (عربي/إنجليزي)
- المدينة
- الحد الأقصى للمشاركين

**الخطوة 3: المراجعة والإرسال**
- عرض جميع البيانات
- رسالة: "سيتم إرسال الفعالية للموافقة"
- **الإرسال** → حالة "Pending"

### 👨‍💼 المدير → الموافقات

1. **صفحة الموافقات**: `/admin-approvals`
2. **قائمة الفعاليات المعلقة**
3. **خيارات**:
   - موافقة فردية (لكل فعالية)
   - رفض مع سبب
   - **الموافقة على الجميع** (Bulk Approve)
4. **إعدادات**:
   - ☑️ "الموافقة التلقائية على جميع الفعاليات المستقبلية"

## 4️⃣ لوحات التحكم

### 🙋 لوحة المستخدم

**الوصول**: أي مستخدم مسجل

**الميزات**:
- **تقويمي**: عرض الفعاليات الشخصية بالألوان
- **حجوزاتي**: قائمة التسجيلات (قادمة/سابقة)
- **حسابي**: تعديل المعلومات الشخصية
- **ملفي الشخصي**: الصورة، النبذة، الاهتمامات
- **الإعدادات**: التذكيرات، الخصوصية، الألوان

### 🎭 لوحة المنظم

**الوصول**: المنظمون (Organizer Role)

**الميزات**:
- **فعالياتي**: قائمة الفعاليات الخاصة
- **إنشاء فعالية**: معالج 3 خطوات
- **إحصائيات الفعالية**:
  - عدد التسجيلات
  - نسبة الحضور
  - التفاعل (مناقشات)
- **إدارة الملفات**: رفع/حذف الصور والمستندات
- **المناقشات**: الرد على تعليقات المشاركين
- **التقارير**: تصدير بيانات الحضور (CSV)

### 👔 لوحة المدير

**الوصول**: المسؤولون (Admin Role)

**الميزات**:
- **الموافقات**: إدارة طلبات الفعاليات
- **إدارة المستخدمين**: عرض/تعديل/حظر
- **إدارة السلايدر**: تخصيص الصفحة الرئيسية
- **إدارة المدن والفئات**: إضافة/تعديل/حذف
- **التقارير الشاملة**:
  - إجمالي الفعاليات
  - أكثر المدن نشاطاً
  - أكثر الفئات شعبية
  - ساعات الذروة
- **الإعدادات العامة**:
  - الموافقة التلقائية
  - reCAPTCHA
  - قوالب المشاركة
  - ألوان الموقع الافتراضية

## 5️⃣ نظام الأدوار والصلاحيات

### الأدوار (Roles)

1. **Admin** (المسؤول)
   - صلاحيات كاملة على النظام
   - الموافقة على الفعاليات
   - إدارة المستخدمين والإعدادات
   - الوصول لجميع التقارير

2. **Organizer** (المنظم)
   - إنشاء وإدارة فعالياته الخاصة
   - رفع الملفات
   - الرد على المناقشات
   - تقارير فعالياته فقط

3. **Editor** (المحرر)
   - تعديل الفعاليات
   - إدارة المحتوى
   - بدون صلاحيات حذف

4. **Support** (الدعم)
   - الرد على الاستفسارات
   - عرض البيانات فقط

5. **Viewer** (المتابع)
   - تصفح الفعاليات
   - التسجيل في الفعاليات
   - المشاركة في المناقشات

### الصلاحيات (Permissions)

- **EventManagement.Events.Default**: عرض الفعاليات
- **EventManagement.Events.Create**: إنشاء فعالية
- **EventManagement.Events.Edit**: تعديل فعالية
- **EventManagement.Events.Delete**: حذف فعالية
- **EventManagement.Events.Approve**: الموافقة على الفعاليات
- **EventManagement.Bookings.Create**: التسجيل في فعالية
- **EventManagement.Bookings.Cancel**: إلغاء الحجز
- **EventManagement.Admin**: الوصول للوحة الإدارة
