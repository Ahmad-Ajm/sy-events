## ⚠️ المشاكل المحتملة والحلول

### 1. السلايدر لا يظهر
**الأسباب:**
- البيانات لم تُضف بنجاح
- Backend لا يعمل
- CORS error

**الحل:**
```sql
-- تحقق من البيانات
docker exec eventmanagement-postgres psql -U postgres -d EventManagementDb -c "SELECT COUNT(*) FROM home_slider_items WHERE \"IsActive\" = true"
```

يجب أن ترى: `6` أو `5`

### 2. أخطاء CORS في Console
**الخطأ:**
```
Access to XMLHttpRequest at 'https://localhost:44388/...' 
from origin 'http://localhost:4200' has been blocked by CORS policy
```

**الحل:**
- تأكد من أن Backend يعمل على 44388
- تحقق من `environment.ts` أن `issuer` ينتهي بـ `/`

### 3. شهادة HTTPS غير موثوقة
**الخطأ:**
```
NET::ERR_CERT_AUTHORITY_INVALID
```

**الحل:**
```bash
dotnet dev-certs https --trust
```

### 4. الصفحات الإدارية لا تفتح
**السبب:** لم تسجل دخول أو ليس لديك صلاحيات

**الحل:**
- سجل دخول كـ admin (admin / 1q2w3E*)
- تأكد من أن الصلاحيات مضبوطة
