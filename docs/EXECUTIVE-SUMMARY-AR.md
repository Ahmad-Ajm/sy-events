# الملخص التنفيذي - منصة إدارة الفعاليات في سوريا 
**الحالة:** مكتمل 85% - جاهز للمرحلة التجريبية

## 📊 نظرة سريعة

### المشروع
إعادة بناء كاملة لمنصة إدارة الفعاليات باستخدام تقنيات مؤسسية احترافية.

### التقنيات الرئيسية

| الجزء | التقنية المستخدمة |
|------|-------------------|
| **الواجهة الخلفية** | C# + ASP.NET Core 9 + ABP Framework 9.3.5 |
| **الواجهة الأمامية** | Angular 20 + LeptonX Theme |
| **قاعدة البيانات** | PostgreSQL 15+ |
| **البنية المعمارية** | Domain-Driven Design + Modular Monolith |
| **المصادقة** | OAuth 2.0 + OpenIddict + JWT |

### التقنيات الإضافية

#### Backend
- **Entity Framework Core 9** - للتعامل مع قاعدة البيانات
- **AutoMapper** - لتحويل البيانات
- **Serilog** - لتسجيل الأحداث
- **Swashbuckle (Swagger)** - لتوثيق API
- **FluentValidation** - للتحقق من صحة البيانات
- **BlobStoring.FileSystem** - لإدارة الملفات والصور
- **Npgsql** - PostgreSQL Provider
- **OpenIddict** - OAuth 2.0 Server

#### Frontend  
- **Bootstrap 5** - للتصميم
- **Bootstrap Icons** - الأيقونات
- **ngx-datatable** - للجداول
- **FullCalendar** - للتقويم
- **RxJS 7.8** - للبرمجة التفاعلية
- **@abp/ng.core** - ABP Angular Core
- **@abp/ng.theme.lepton-x** - LeptonX Theme
- **@abp/ng.oauth** - OAuth Integration

#### DevOps & Tools
- **Docker & Docker Compose** - للحاويات
- **Redis 7** - للتخزين المؤقت
- **pgAdmin** - لإدارة PostgreSQL
- **GitHub Actions** - للـ CI/CD (مُعد لكن غير مربوط بمستودع)
- **MCP Chrome Tools** - لاختبار المنصة في المتصفح وفحص الأخطاء
