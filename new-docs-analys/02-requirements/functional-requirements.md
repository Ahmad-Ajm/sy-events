# المتطلبات الوظيفية (Functional Requirements)

لكل متطلب: المعرف، الاسم، الوصف، المستخدمون، التدفق، وشروط القبول.

- FR-001: إدارة الفعاليات (CRUD)
  - الوصف: إنشاء/عرض/تحديث/حذف فعالية مع الحقول الأساسية وربط المدينة/التصنيف/المنظم.
  - المستخدمون: Admin, Organizer (ضمن صلاحياته)
  - التدفق: Organizer ينشئ مسودة → يحدّث → يرسل للاعتماد.
  - القبول: 
    - Given مستخدم منظم، When ينشئ فعالية ببيانات صالحة، Then تُحفظ كمسودة.
    - Given فعالية قائمة، When يعدّل حقولًا صالحة، Then تُحدّث القيم وتُسجّل.

- FR-002: سياسة الموافقات (Approve/Reject/Publish/Hide)
  - الوصف: اعتماد أو رفض الفعاليات، نشر/إخفاء.
  - المستخدمون: Admin
  - القبول:
    - Given فعالية Pending، When يعتمدها Admin، Then Status=Approved وIsApproved=true.
    - Given فعالية Approved، When Hide، Then لا تظهر في القوائم العامة.

- FR-003: قائمة الفعاليات مع فلاتر
  - الوصف: استعراض/بحث بفلترة المدينة/التصنيف/الحالة/الفترة/النص.
  - المستخدمون: جميع الأدوار
  - القبول: Given فلاتر صحيحة، When طلب GET، Then يعود Page متوافق مع الفلاتر.

- FR-004: الفعاليات الشعبية والقادمة
  - الوصف: إرجاع Popular (آخر 30 يومًا) وUpcoming.
  - المستخدمون: عام
  - القبول: Given count=10، When GET popular، Then تُعاد 10 عناصر مرتّبة.

- FR-005: حجوزات/متابعة الفعاليات
  - الوصف: متابعة/إلغاء متابعة فعالية (Booking) وتأكيد حضور.
  - المستخدمون: Viewer, Organizer, Admin
  - القبول:
    - Given مستخدم، When follow-event(eventId)، Then يُنشأ Booking فريد (UserId,EventId).
    - Given Booking، When confirm-attendance، Then Status=Attended مع AttendedAt.

- FR-006: رفع الملفات للفعالية
  - الوصف: رفع عدة ملفات (3 صور + PDF + TXT)، توليد صور مصغّرة WebP، قائمة/حذف.
  - المستخدمون: Organizer, Admin
  - القبول: Given ملفات صالحة، When upload-multiple، Then تُحفظ وتظهر في القائمة.

- FR-007: إدارة المدن والتصنيفات
  - الوصف: CRUD للمدن والتصنيفات وربطها بالفعاليات.
  - المستخدمون: Admin
  - القبول: Given إدخال صحيح، When Create، Then يُضاف ويُفهرس بالاسمين (AR/EN).

- FR-008: إدارة المستخدمين والأدوار (أساسي)
  - الوصف: عرض/تعديل بيانات المستخدم ودوره (ضمن واجهات ABP Administration).
  - المستخدمون: Admin
  - القبول: Given مستخدم، When تغيير الدور، Then تُحدّث الصلاحيات الفعّالة.

- FR-009: التقويم الملوّن للمستخدم
  - الوصف: Endpoint يعيد فعاليات المستخدم بالحالات اللونية + واجهة عرض.
  - المستخدمون: Viewer/Organizer/Admin
  - القبول: Given بيانات، When GET calendar، Then تُعاد حالات صحيحة وتظهر في الواجهة.

- FR-010: التقارير وتصدير CSV
  - الوصف: تقارير أساسية (فعاليات/حجوزات/مستخدمين) مع تصدير CSV.
  - المستخدمون: Admin
  - القبول: Given فلاتر، When Export CSV، Then يُنزّل ملف بصيغة صحيحة وترميز صحيح.

- FR-011: التعريب وRTL
  - الوصف: عرض الواجهة بالعربية/الإنجليزية مع RTL، نصوص ضمن ملفات i18n.
  - المستخدمون: جميع الأدوار
  - القبول: Given لغة AR، When استعراض الصفحات، Then تُطبّق RTL والموارد المترجمة.

- FR-012: المصادقة والتفويض
  - الوصف: OpenIddict + JWT، سياسات/صلاحيات ABP على الخدمات.
  - المستخدمون: جميع الأدوار
  - القبول: Given صلاحية مفقودة، When استدعاء محمي، Then 403 Forbidden.
