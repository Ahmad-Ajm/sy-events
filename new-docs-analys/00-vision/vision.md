# رؤية المشروع (Vision)
- **المشكلة**: إدارة الفعاليات في سوريا مشتتة عبر قنوات متعددة (نشرات، صفحات اجتماعية، جداول يدوية)، مما يصعّب الاكتشاف، الحجز، المتابعة، والتقارير. لا توجد منصة موحّدة تدعم العربية وRTL وتوفّر صلاحيات دقيقة، موافقات، وملفات للفعاليات.
- **الحل**: بناء منصة موحّدة لإدارة الفعاليات باستخدام ABP Framework (.NET 8) وAngular مع ثيم LeptonX، وقاعدة بيانات PostgreSQL. المنصة توفّر: CRUD للفعاليات، نظام موافقات، حجوزات/متابعة، رفع ملفات وصور مصغّرة، تقويم ملوّن للحضور، تقارير وتصدير CSV، تعددية المستأجرين، ودعم كامل RTL والتعريب.
- **القيمة**: 
  - تقليل زمن اعتماد الفعاليات وتحسين الجودة.
  - رفع معدل اكتشاف الفعاليات ومشاركة المستخدمين.
  - توحيد الإجراءات والبيانات وتحسين التقارير.
  - KPIs: p95 للطلبات الأساسية (Home ≤ 200ms، Popular ≤ 250ms، Calendar ≤ 300ms)، زيادة عدد الفعاليات المعتمدة شهريًا، معدل متابعة/حضور الفعاليات. القيم العددية المستهدفة: "القيمة غير واضحة في المشروع".
- **النطاق الزمني**: 
  - MVP: أساسيات (فعاليات، مدن/تصنيفات، موافقات، حجوزات متابعة، رفع ملفات، تقارير أساسية، i18n/RTL، LeptonX، OAuth/OpenIddict، Swagger).
  - مراحل لاحقة: تقويم متقدّم وربط بيانات حيّة، إعدادات SEO، CMS بسيط، تنبيهات/تذكيرات، Social Share، تكاملات RAG/n8n، تخصيص الثيم.
- **الجمهور المستهدف**: 
  - Admin: إدارة النظام والموافقات والتقارير والإعدادات.
  - Organizer: إنشاء فعالياته وإدارتها وتحليل الأداء.
  - Viewer: اكتشاف الفعاليات والمتابعة والحضور.
