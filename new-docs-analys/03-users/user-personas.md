# نماذج المستخدمين (Personas)

- المشرف (Admin)
  - الأهداف: ضمان جودة المحتوى، سرعة الموافقات، أمان وصلاحيات دقيقة، تقارير صحيحة.
  - المهام: اعتماد/رفض الفعاليات، إدارة المدن/التصنيفات/المستخدمين، ضبط الإعدادات، تصدير التقارير.
  - الآلام: ازدحام الموافقات، بيانات ناقصة، أخطاء إدخال، بطء تقارير.

- المنظّم (Organizer)
  - الأهداف: نشر فعاليات بسرعة، إدارة ملفات وصور، متابعة الحضور، رؤية مؤشرات أساسية.
  - المهام: إنشاء/تعديل فعالية، رفع ملفات، طلب اعتماد، استعراض المتابعة/الحضور.
  - الآلام: دورة اعتماد طويلة، رفع ملفات مقيّد، نقص أدوات تحسين الظهور.

- المشارك/المشاهد (Viewer)
  - الأهداف: اكتشاف فعاليات مناسبة، متابعة/حجز بسهولة، تذكيرات قبل الموعد.
  - المهام: تصفّح، فلترة، متابعة فعالية، تأكيد الحضور في الموعد.
  - الآلام: نتائج غير دقيقة، صعوبة العودة بعد تسجيل الدخول، ضعف تجربة RTL.
